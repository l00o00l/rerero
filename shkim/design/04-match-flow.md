# 04. 매치 플로우

## 전체 흐름

1. 홈
2. 랭크전 참가
3. 자동 매칭
4. 매치 준비
5. 카운트다운
6. 30분 러닝
7. GPS 기록 검증
8. 결과 리포트
9. 보상 지급
10. 재경기 또는 홈 복귀

## 홈

홈 화면은 바로 경기에 들어갈 수 있어야 한다.

주요 정보:

- 현재 티어
- 랭크 점수
- 보유 코인
- 최근 전적
- 오늘의 러닝 상태
- 랭크전 참가 버튼

## 자동 매칭

유저가 랭크전 참가를 누르면 매칭 대기 상태가 된다.

표시 정보:

- 현재 티어
- 예상 대기 시간
- 매칭 규칙
- 취소 버튼

매칭 우선순위:

1. 같은 티어
2. 인접 티어
3. 일정 시간 이후 매칭 실패 처리

## 매치 준비

상대가 잡히면 경기 준비 화면으로 이동한다.

표시 정보:

- 내 닉네임, 티어, 전적
- 상대 닉네임, 티어, 전적
- 경기 규칙
- 보상 안내
- 안전 안내

유저가 준비 완료를 누르면 카운트다운으로 넘어간다.

## 카운트다운

카운트다운은 게임감을 주는 첫 장면이다.

연출:

- 5초 카운트다운
- 진동
- 시작 사운드
- 양쪽 아바타 출발 연출

## 러닝 중

러닝 중에는 조작을 줄인다.

HUD:

- 남은 시간
- 현재 거리
- 현재 페이스
- 상대와의 거리 차이
- 체크포인트 상태

알림:

- 10분 체크포인트
- 20분 체크포인트
- 마지막 5분
- 경기 종료
- 상대 추월/역전

주의:

- 복잡한 아이템 버튼은 넣지 않는다.
- 지도 위 상대 위치를 실시간으로 보여주는 기능은 MVP에서 제외한다.
- 안전 안내는 과하게 방해하지 않되, 첫 사용 시 명확히 제공한다.

## 체크포인트

체크포인트는 10분, 20분, 30분이다.

각 체크포인트에서 기록:

- 내 누적 거리
- 상대 누적 거리
- 리드 유저
- 거리 차이
- 내 평균 페이스

체크포인트는 경기 후 리포트의 핵심 재료가 된다.

## 경기 종료

30분이 지나면 자동으로 경기가 종료된다.

종료 후 처리:

1. GPS 기록 저장
2. 비정상 속도 검사
3. 순간이동 검사
4. GPS 신호 품질 검사
5. 결과 확정

기록이 의심스러운 경우:

- 결과 보류
- 랭크 반영 보류
- 유저에게 기록 검토 안내

## 결과 리포트

결과 리포트는 런닝메이트가 게임처럼 느껴지는 가장 중요한 화면이다.

구성:

- 승패 연출
- 최종 거리 비교
- 체크포인트별 그래프
- 아바타 레이스 재생
- 역전 시점 표시
- 랭크 점수 변화
- 코인 보상
- 배지/칭호 진행도

## 보상

보상은 승리 보상과 완주 보상으로 나눈다.

승자:

- 랭크 점수 상승
- 승리 코인
- 완주 코인
- 배지 진행도

패자:

- 랭크 점수 하락
- 완주 코인
- 배지 진행도

패자는 코인을 잃지 않는다.

## 재경기

결과 화면에서 바로 다음 행동을 선택할 수 있어야 한다.

- 다시 매칭
- 리포트 공유
- 프로필 꾸미기
- 홈으로 돌아가기
