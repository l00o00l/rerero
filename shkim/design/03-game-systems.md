# 03. 게임 시스템

## 개인전

개인전은 런닝메이트의 기본 모드다.

MVP:

- 1:1 자동 매칭
- 30분 거리전
- 티어 기반 랭크
- 승리 코인 보상

장기 확장:

- 5km 기록전
- 페이스 유지전
- 비동기 기록 제출전
- 시즌 이벤트전

## 팀전

팀전은 장기 확장 기능이다.

후보 모드:

- 2v2 팀 합산 거리전
- 3v3 팀 합산 거리전
- 팀 평균 페이스전
- 팀 체크포인트 점령전

팀전의 핵심은 개인 기록보다 팀 합산 결과다. 유저가 못 뛰는 날에도 팀원과 전략을 이야기하게 만드는 것이 목표다.

## 커스텀 방

커스텀 방은 스타크래프트식 방 만들기/입장 구조를 참고한다.

방장이 설정할 수 있는 항목:

- 경기 모드
- 개인전/팀전
- 제한 시간
- 목표 거리
- 참여 인원
- 공개/비공개
- 티어 제한
- 코인 보상 여부
- 벌칙/약속 기록 여부

커스텀 방은 랭크보다 소셜 플레이에 가깝다. 따라서 랭크 점수 반영 여부는 방 설정에 따라 제한해야 한다.

## 자동 매칭

자동 매칭은 게임의 기본 진입점이다.

MVP 기준:

- 티어 기반 1:1 매칭
- 30분 거리전 고정
- 랭크 점수 반영

장기 기준:

- 개인전 랭크 매칭
- 팀전 랭크 매칭
- 비동기 매칭
- 이벤트 매칭

## 랭크

랭크는 유저가 계속 플레이할 이유를 만든다.

MVP 티어:

- 루키
- 브론즈
- 실버
- 골드

장기 티어:

- 플래티넘
- 다이아
- 마스터
- 챌린저

랭크 점수:

- 승리 시 상승
- 패배 시 하락
- 부정 기록 판정 시 무효 처리
- 경기 포기 시 패배 처리

## 승급전

승급전은 MVP 이후 추가한다.

예시:

- 티어 승급 점수 도달 시 승급전 발생
- BO3 또는 BO5 형태
- 승급전은 실시간 매칭 비중을 높인다
- 승급 성공 시 전용 연출과 보상 지급

승급전은 게임 느낌이 강하지만, 초기 유저 풀이 작으면 매칭 대기가 길어질 수 있다. MVP 이후 데이터가 쌓인 뒤 도입한다.

## 코인

코인은 승리와 완주를 보상하는 비현금성 게임 재화다.

획득처:

- 승리
- 완주
- 체크포인트 성과
- 일일/주간 미션
- 시즌 보상

사용처:

- 프로필 프레임
- 칭호
- 아바타 의상
- 러닝 이펙트
- 경기 입장 연출
- 승리 포즈
- 팀 엠블럼

코인은 패배 시 차감하지 않는다. 패배 페널티는 랭크 점수로 충분하다.

## 내기와 보상

팀전 또는 커스텀 방에서 "내기"는 현금성 도박이 아니라 비현금성 보상/약속 시스템으로 정의한다.

가능:

- 게임 코인 보상
- 칭호/배지 걸기
- 팀 명예 점수
- 인증 미션
- 커피/밥 같은 약속 기록

불가:

- 현금
- 상품권
- 환금 가능한 포인트
- 외부 결제 정산
- 강제 채무 구조

## 성장과 수집

MVP에서는 얇게 시작한다.

- 기본 프로필 프레임
- 칭호
- 간단한 아바타
- 승리 포즈
- 경기 입장 이펙트

장기적으로는 시즌 보상, 팀 엠블럼, 한정 스킨, 지역 리그 배지를 추가할 수 있다.
