# 02. MVP 범위

## MVP 목표

첫 버전의 목표는 많은 기능을 넣는 것이 아니다. 다음 질문에 답하는 것이다.

> 유저가 티어 기반 자동 매칭 1:1 30분 거리전을 재미있다고 느끼고, 다시 뛰고 싶어 하는가?

## MVP 핵심 모드

### 1:1 자동 매칭 30분 거리전

유저는 랭크전 참가 버튼을 누르고 자동 매칭을 기다린다. 매칭이 성사되면 두 유저는 같은 규칙으로 30분 동안 달린다. 더 긴 거리를 기록한 유저가 승리한다.

규칙:

- 경기 시간: 30분
- 승리 조건: GPS 기준 총 거리
- 체크포인트: 10분, 20분, 30분
- 보상: 승자 코인 + 양쪽 완주 보상
- 랭크: 승자는 점수 상승, 패자는 점수 하락
- 패배 코인 페널티: 없음

## 티어

MVP 티어는 작게 시작한다.

- 루키
- 브론즈
- 실버
- 골드

상위 티어는 유저 풀이 충분해진 뒤 추가한다.

## 매칭

MVP 매칭은 티어 기반으로 시작한다.

우선순위:

1. 같은 티어 유저
2. 대기 시간이 길면 인접 티어 유저
3. 매칭 실패 시 비동기 매치 또는 봇 기록 매치는 추후 검토

초기에는 유저 풀이 작을 가능성이 높으므로 매칭 조건을 과하게 세분화하지 않는다.

## 체크포인트

체크포인트는 10분, 20분, 30분에 발생한다.

목적:

- 경기 중간 목표를 만든다.
- "그냥 30분 뛰기"보다 게임처럼 느끼게 한다.
- 경기 후 리포트에서 역전/격차/페이스 변화를 보여줄 수 있다.

MVP 체크포인트 보너스는 단순해야 한다.

- 각 체크포인트 시점의 리드 유저를 표시한다.
- 체크포인트 달성 뱃지 또는 소량 코인 보너스를 줄 수 있다.
- 승패 자체는 최종 거리로만 결정한다.

## 코인

코인은 현금성 재화가 아니다.

획득:

- 승리 보상
- 완주 보상
- 일일 첫 경기 보상
- 시즌/이벤트 보상

사용:

- 프로필 프레임
- 칭호
- 기본 아바타 꾸미기
- 경기 입장 연출
- 승리 포즈

제한:

- 현금 구매 없음
- 환전 없음
- 상품권 교환 없음
- 외부 결제 보상 없음

## 러닝 중 UX

러닝 중에는 안전이 우선이다.

보여줄 정보:

- 남은 시간
- 현재 거리
- 현재 페이스
- 상대와의 거리 차이
- 체크포인트 알림

입력:

- 경기 포기
- 일시 정지 여부는 신중히 검토
- 달리는 중 아이템 사용 같은 조작은 MVP에서 제외

알림:

- 음성 안내
- 진동
- 간단한 화면 표시

## 경기 후 UX

경기 후 화면이 게임감을 책임진다.

필수 요소:

- 승패 결과
- 내 거리와 상대 거리
- 체크포인트별 리드 변화
- 랭크 점수 변화
- 코인 보상
- 아바타 레이스 리포트
- 획득 배지/칭호 진행도

## MVP 성공 기준

정량 지표:

- 첫 경기 완료율
- 매칭 후 실제 러닝 시작률
- 30분 완주율
- 7일 내 재경기율
- 패배 후 재경기율

정성 지표:

- "혼자보다 더 뛰게 됐다"는 피드백
- "상대를 이기고 싶었다"는 피드백
- "운동 앱보다 게임 같았다"는 피드백

## MVP 제외 범위

- 팀전
- 커스텀 방
- 친구 초대 방
- 승급전
- 시즌제
- 복잡한 상점
- 아이템전
- 실시간 상대 지도 표시
- 워치 연동
- 외부 러닝 앱 연동
