# 런닝메이트 기획 문서

런닝메이트는 실제 러닝 기록을 모바일 게임의 매치, 랭크, 보상 구조로 바꾸는 GPS 기반 러닝 경쟁 게임이다.

초기 버전은 1인 개발 범위를 고려해 `티어 기반 자동 매칭 1:1 30분 거리전`에 집중한다. 장기적으로는 커스텀 방, 팀전, 승급전, 시즌제, 보상형 내기 구조까지 확장한다.

## 현재 확정 방향

- 플랫폼: 모바일
- 핵심 입력: 스마트폰 GPS 러닝 기록
- MVP 모드: 티어 기반 자동 매칭 1:1 30분 거리전
- 게임성: 랭크, 코인 보상, 체크포인트, 아바타 레이스 리포트, 꾸미기
- 러닝 중 UX: 안전 우선, 조작 최소화, 음성/진동/간단 HUD 중심
- 현금성 보상: 제외

## 핵심 한 줄

> 내 티어의 상대와 자동 매칭되어 30분 동안 실제로 달리고, 승리하면 랭크와 코인 보상을 얻는 러닝 게임.
