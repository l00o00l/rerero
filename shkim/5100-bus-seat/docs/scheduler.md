# Windows Scheduler

수집기는 로컬 Windows PC에서 실행된다. 가장 큰 운영 리스크는 절전 모드 때문에 피크 시간대 데이터가 비는 것이다.

## Recommendation

Windows 작업 스케줄러에 수집기 실행 작업을 등록하고, 절전 모드 해제 옵션을 켠다.

## Settings

작업 스케줄러에서 새 작업을 만들 때 다음 설정을 사용한다.

```text
일반:
- 사용자가 로그온되어 있는지 여부와 관계없이 실행
- 가장 높은 수준의 권한으로 실행

트리거:
- 평일 04:55 시작
- 필요하면 퇴근 시간대 전 별도 트리거 추가

조건:
- 이 작업을 실행하기 위해 컴퓨터의 절전 모드 해제 켜기

설정:
- 작업이 실패하면 다시 시작
- 이미 실행 중이면 새 인스턴스 시작 안 함
```

## Runtime Window

작업 스케줄러는 수집기 프로세스를 깨우는 역할만 한다. 실제 수집 시간창 판단은 수집기 코드 안에서도 한다.

```text
수집 시간:
- 평일 05:00-10:00 KST
- 평일 17:30-20:30 KST
```

이중으로 제한하는 이유는 수동 실행이나 재시작 상황에서도 시간창 밖 호출을 막기 위해서다.

## Sleep Risk

노트북을 닫거나 네트워크가 끊기면 데이터가 빈다. 이 프로젝트는 로컬 검증용이므로 완전한 무중단 수집은 목표가 아니다.
