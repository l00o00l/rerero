# Dream Laundromat

상세 기획 문서는 [dream-laundromat-planning/README.md](dream-laundromat-planning/README.md)에 정리한다.

## One Line Pitch

손님들의 꿈 조각을 세탁, 건조, 염색, 접기 과정을 거쳐 원하는 상태로 돌려주는 한 손 퍼즐.

## Player Fantasy

플레이어는 밤마다 열리는 이상한 세탁소의 주인이다. 손님들은 악몽, 추억, 비밀, 후회가 묻은 꿈을 맡기고, 플레이어는 제한된 기계와 바구니를 사용해 꿈을 깨끗하거나 원하는 감정으로 바꿔 돌려준다.

## Core Loop

1. 손님 주문과 꿈 조각 상태를 확인한다.
2. 꿈 조각을 세탁기, 건조기, 염색기, 접는 테이블, 보관 바구니 사이에서 이동한다.
3. 꿈의 얼룩, 색, 감정, 크기를 목표 상태로 변환한다.
4. 모든 주문을 맞추면 클리어하고, 잘못 변환하거나 공간이 막히면 재시도한다.

## One-Hand Control

- 꿈 조각 탭: 선택
- 기계/바구니 탭: 이동
- 꿈 조각 드래그: 직접 배치
- 되돌리기 버튼: 마지막 이동 취소
- 홀드: 꿈 조각의 현재 상태와 변환 예측 보기

## Puzzle Rules

- `악몽 얼룩`은 세탁기에 넣으면 제거된다.
- `슬픔 얼룩`은 따뜻한 건조기를 거치면 `추억`으로 변한다.
- `색 꿈`은 염색기에서 목표 색으로 바뀐다.
- `젖은 꿈`은 바로 제출할 수 없고 건조가 필요하다.
- `접힌 꿈`은 보관 공간을 적게 차지하지만 일부 기계에 넣기 전에 펼쳐야 한다.
- `찢어진 꿈`은 같은 색 실 조각과 합쳐야 복구된다.
- 서로 다른 색 꿈을 같이 넣으면 색이 섞인다.
- 같은 감정 꿈을 한 번에 처리하면 콤보 보너스가 붙는다.

## Level Production Model

- 손님 수
- 주문 수
- 꿈 조각 수
- 기계 종류와 슬롯 수
- 보관 바구니 수
- 꿈 상태 조합: 색, 감정, 젖음, 접힘, 얼룩, 손상
- 제한 턴
- 제출 순서 조건
- 기계별 변환 규칙

이 구조는 레벨을 많이 만들기 좋다. 같은 꿈 조각이라도 기계 배치, 슬롯 제한, 목표 순서만 바꿔도 다른 풀이가 나온다.

## Difficulty Curve

- 1-5레벨: 이동, 주문 판독, 제출
- 6-7레벨: 세탁과 악몽 얼룩
- 8-10레벨: 건조와 세탁 -> 건조 -> 제출 체인
- 11-25레벨: 보관 바구니와 공간 압박
- 26-35레벨: 색 변환
- 36-45레벨: 접기/펼치기와 capacity 압박
- 46레벨 이후: 특수 주문, 감정 변환, 수선, 이벤트 규칙 조합

## Event And LiveOps Fit

- `악몽 주간`: 악몽 얼룩과 어두운 색 꿈 비중 증가
- `여름휴가 꿈`: 바다, 여행, 낮잠 테마 스킨
- `고양이 꿈`: 꿈 조각이 가끔 자리를 바꾸는 이벤트 규칙
- `크리스마스 꿈`: 선물 포장처럼 접기/포장 목표 추가
- 일일 퍼즐: 제한된 기계 조합으로 한 개의 고난도 주문 해결

## Prototype Scope

- 슬롯 기반 세탁소 UI
- 꿈 조각 3종: 일반, 악몽 얼룩, 젖은 꿈
- 기계 2종: 세탁기, 건조기
- 보관 바구니 2개
- 손님 주문 3개
- 10개 수제 레벨
- 되돌리기 1단계

## Release Potential

강점은 컨셉이 기억에 남고, 레벨 파라미터가 풍부하며, 이벤트 테마가 매우 자연스럽다는 점이다. Sort 퍼즐의 직관성에 변환 퍼즐과 공간 퍼즐을 섞을 수 있다.

약점은 상태가 많아질수록 UI가 복잡해질 수 있다는 점이다. 꿈 조각 상태를 색, 아이콘, 애니메이션으로 즉시 이해시키는 UX가 중요하다.

## Risks

- 상태 아이콘이 많아지면 모바일 화면에서 읽기 어려울 수 있다.
- 색 섞기 규칙은 직관적이지 않으면 혼란을 만든다.
- 기계 대기 시간이나 애니메이션이 길면 반복 플레이 속도가 떨어질 수 있다.
- 레벨 자동 생성 전에 수제 레벨 제작 비용이 커질 수 있다.
