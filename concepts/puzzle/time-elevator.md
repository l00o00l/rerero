# Time Elevator

## One Line Pitch

과거, 현재, 미래를 오가는 엘리베이터에 물건과 생명체를 태워, 변하기 전이나 변한 뒤에 올바른 시대에 내려주는 퍼즐.

## Player Fantasy

플레이어는 시간 빌딩의 엘리베이터 운전사다. 씨앗, 음식, 로봇, 아기 용, 유물 같은 대상은 시간 층을 지나며 상태가 바뀐다. 목적은 원하는 상태가 되는 정확한 순간에 내려주는 것이다.

## Core Loop

1. 각 승객/물건의 목표 시대와 목표 상태를 확인한다.
2. 엘리베이터 정원 안에서 태울 대상을 고른다.
3. 엘리베이터를 위/아래로 이동하며 시간 변화를 계산한다.
4. 올바른 층과 상태에서 내려 클리어한다.

## One-Hand Control

- 대상 탭: 태우기/내리기
- 층 버튼 탭: 이동
- 엘리베이터 내부 슬롯 드래그: 순서 변경
- 대상 홀드: 시간 변화 미리보기
- 되돌리기: 마지막 이동 취소

## Puzzle Rules

- `씨앗`은 미래로 가면 `새싹`, 더 가면 `나무`가 된다.
- `음식`은 시간이 지나면 `숙성`, 더 지나면 `부패`한다.
- `아기 용`은 미래로 가면 `성체 용`, 더 가면 `늙은 용`이 된다.
- `로봇`은 과거로 가면 `부품`, 미래로 가면 `고장난 로봇`이 된다.
- `얼음`은 현재/미래에서 `물`, 더 지나면 `증기`가 된다.
- 일부 대상은 특정 시대를 지나면 금지 상태가 된다.
- 같은 시대 승객을 한 번에 내리면 콤보가 붙는다.

## Level Production Model

- 시대 층 수
- 대상 수
- 엘리베이터 정원
- 대상별 변화 단계
- 목표 상태
- 금지 시대
- 이동 횟수 제한
- 특수 층 효과

레벨 생산성은 중간-높음이다. 변화 체인이 많아질수록 레벨을 많이 만들 수 있지만, 유저가 기억해야 할 정보도 늘어난다.

## Difficulty Curve

- 1-10레벨: 과거/현재/미래 3층, 단순 변화 2단계
- 11-20레벨: 변화 3단계 대상 추가
- 21-35레벨: 금지 상태와 부패/고장 추가
- 36-50레벨: 엘리베이터 정원 제한 강화
- 51레벨 이후: 특수 층, 동시 배송, 순서 조건 추가

## Event And LiveOps Fit

- `공룡 시대 이벤트`: 알, 공룡, 화석 변화
- `미래 도시 이벤트`: 로봇, 배터리, AI 유물
- `요리 숙성 이벤트`: 음식 숙성 타이밍 퍼즐
- `역사 박물관 챌린지`: 유물을 올바른 시대에 복원

## Prototype Scope

- 3개 층: 과거, 현재, 미래
- 엘리베이터 정원 3칸
- 대상 4종: 씨앗, 음식, 로봇, 얼음
- 변화 단계 표시 UI
- 10개 수제 레벨
- 되돌리기 1단계

## Release Potential

강점은 한 문장으로 설명되는 컨셉과 명확한 퍼즐성이 있다는 점이다. 시간 변화는 시각적으로 보여주기 좋고, 이벤트 테마도 다양하게 붙는다.

약점은 대상별 변화 규칙이 많아지면 암기 게임처럼 느껴질 수 있다는 점이다. 변화 미리보기와 튜토리얼이 핵심이다.

## Risks

- 변환 규칙을 모르면 해답을 추론하기 어렵다.
- 엘리베이터 이동 애니메이션이 길면 반복 플레이가 느려진다.
- 많은 레벨을 만들려면 변화 체인을 데이터화하고 검증 도구를 만들어야 한다.
- 기존 sort/elevator 퍼즐과 차별화하려면 시간 변화 연출이 강해야 한다.

## Open Questions

- 층은 3개로 고정할지, 챕터마다 늘릴지 정해야 한다.
- 시간 변화는 엘리베이터 이동마다 일어나는가, 특정 층을 지날 때만 일어나는가?
- 실패 조건은 제한 이동 수, 금지 상태, 잘못된 제출 중 무엇을 중심에 둘 것인가?
