# 07. UX / Interaction

`Dream Laundromat`은 상태가 많아질 수 있는 게임이다. 그래서 UX의 핵심은 "조작보다 정보 판독"이다. 유저가 꿈 조각 상태와 주문 목표를 즉시 이해하지 못하면 퍼즐 재미가 사라진다.

## Screen Layout

세로 화면 기본 구조:

```text
[Top]    손님 주문 / 진행 상태
[Middle] 기계, 바구니, 꿈 조각 작업 영역
[Bottom] 되돌리기, 재시작, 힌트, 남은 턴
```

### Top: Orders

- 손님 카드 1-3개 표시
- 각 카드에 필요한 꿈 상태 아이콘 표시
- 완료된 주문은 즉시 접히거나 체크 처리
- 긴 텍스트 설명은 사용하지 않음

### Middle: Work Area

- 기계는 중앙에서 가장 눈에 띄게 배치
- 바구니는 기계 주변에 배치
- 처리 대기 꿈은 하단 중간 또는 왼쪽 하단에 배치
- 손가락이 가리는 문제를 줄이기 위해 선택 시 확대 프리뷰 제공

### Bottom: Actions

- Undo
- Restart
- Hint
- Move counter

한 손 조작 기준으로 오른손/왼손 옵션을 나중에 고려한다.

## Interaction Model

초기 조작은 `탭 선택 -> 탭 목적지`를 기본으로 한다.

이유:

- 드래그보다 실수율이 낮다.
- 작은 화면에서 정확하다.
- 접근성이 좋다.
- 슬롯 기반 퍼즐과 잘 맞는다.

보조 조작:

- 드래그 앤 드롭은 지원하되 필수로 만들지 않는다.
- 꿈 조각 홀드 시 상태와 변환 예측을 보여준다.
- 기계 홀드 시 기계 설명과 처리 결과를 보여준다.

## State Readability

꿈 조각 상태는 중첩 가능하지만, 표시 우선순위를 둔다.

우선순위:

1. 실패/제출 불가 상태
2. 주문 목표와 관련된 상태
3. 현재 기계에서 바뀔 상태
4. 장식적 상태

예:

- 악몽 얼룩: 가장 눈에 띄는 얼룩 아이콘
- 젖음: 물방울/광택 효과
- 색: 꿈 조각 본체 색
- 접힘: 형태 변화
- 찢어짐: 갈라진 선
- 감정: 작은 표정 또는 오라

## Transformation Preview

유저가 꿈 조각을 선택하고 기계 위에 올리거나 목적지를 탭하기 전에 결과를 보여준다.

예:

```text
stain=Nightmare, moisture=Dry + Washer -> stain=None, moisture=Wet
moisture=Wet + Dryer -> moisture=Dry
color=Blue + Washer(후속 규칙) -> color=FadedBlue, moisture=Wet
```

프리뷰가 필요한 이유:

- 복잡한 상태 변환을 외우지 않아도 된다.
- 실수로 인한 좌절을 줄인다.
- 퍼즐을 계획하는 느낌이 강해진다.

## Error Handling

잘못된 이동은 무조건 막기보다, 상황에 따라 다르게 처리한다.

막아야 하는 행동:

- 남은 capacity가 없는 곳으로 이동
- 해당 기계가 절대 처리할 수 없는 상태 넣기
- 이미 완료된 주문에 추가 제출

허용하되 경고할 행동:

- 주문과 맞지 않는 상태로 제출 시도
- 색이 빠질 수 있는 세탁
- 접힌 꿈을 처리할 수 없는 기계에 넣기 전 시도

## Tutorial UX

튜토리얼은 텍스트보다 조작 유도를 우선한다.

- 첫 레벨: 손님 카드와 맞는 꿈 조각을 강조
- 세탁기 첫 등장: 얼룩 꿈과 세탁기만 강조
- 건조기 첫 등장: 젖은 상태와 건조 결과 강조
- 바구니 압박: 남은 capacity가 사라지는 순간 안내

튜토리얼 문장은 가능하면 8단어 이하로 유지한다.

## Accessibility

- 색상만으로 상태를 구분하지 않는다.
- 모든 주요 상태에 형태/아이콘 차이를 둔다.
- 햅틱은 보조 피드백으로만 사용한다.
- 애니메이션 속도는 빠르게 유지하되, 중요한 변화는 너무 순식간에 지나가지 않게 한다.

## UX Risks

- 상태가 4개 이상 겹치면 꿈 조각이 지저분해질 수 있다.
- 손님 주문이 많으면 상단 UI가 과밀해진다.
- 변환 프리뷰가 너무 많은 정보를 보여주면 오히려 느려진다.

대응:

- 한 레벨에서 핵심 상태는 2-3개로 제한
- 주문 카드는 최대 3개부터 시작
- 프리뷰는 "변하는 것만" 보여주기
