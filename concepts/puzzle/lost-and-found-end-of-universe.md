# Lost & Found at the End of the Universe

## One Line Pitch

우주 끝 분실물 센터에서 이상한 물건들의 속성을 안정화해 올바른 주인에게 돌려주는 퍼즐.

## Player Fantasy

플레이어는 우주의 마지막 역에 있는 분실물 센터 직원이다. 이곳에는 중력이 반대로 흐르는 우산, 주인을 바꾸는 반지, 복제되는 열쇠, 시간을 먹는 장난감 같은 물건들이 모인다.

## Core Loop

1. 분실물과 주인의 요구 조건을 확인한다.
2. 보관함, 안정화 장치, 분류 레일 사이에서 물건을 이동한다.
3. 물건의 위험 속성을 제거하거나 원하는 상태로 만든다.
4. 주인 조건에 맞게 제출한다.

## One-Hand Control

- 물건 탭: 선택
- 보관함 탭: 이동
- 장치 탭: 변환 또는 안정화
- 물건 홀드: 속성 설명과 위험 범위 표시
- 되돌리기: 마지막 이동 취소

## Puzzle Rules

- `반중력 우산`은 위쪽 슬롯으로만 이동한다.
- `복제 열쇠`는 같은 물건 옆에 있으면 하나 더 생긴다.
- `주인 바꾸는 반지`는 가장 가까운 주문의 주인을 바꾼다.
- `시간 장난감`은 턴이 지날수록 낡고, 너무 낡으면 제출할 수 없다.
- `별 조각`은 특수 상자에 넣어야 안정화된다.
- `블랙홀 지갑`은 주변 작은 물건을 빨아들인다.
- `깨진 사진`은 같은 주인 물건과 붙여야 복구된다.

## Level Production Model

- 물건 수
- 주인 수
- 보관함 크기
- 안정화 장치 종류
- 위험 속성 수
- 제출 순서
- 턴 제한
- 물건 간 상호작용 거리

레벨 생산성은 좋지만, 속성 규칙이 너무 자유로우면 QA가 어려워질 수 있다. 속성을 작은 규칙 모듈로 제한해야 한다.

## Difficulty Curve

- 1-10레벨: 단순 색/주인 매칭
- 11-20레벨: 방향 제약 물건 추가
- 21-35레벨: 턴마다 상태가 변하는 물건 추가
- 36-50레벨: 인접 상호작용 추가
- 51레벨 이후: 복제, 흡수, 주인 변경 같은 고위험 규칙 조합

## Event And LiveOps Fit

- `외계 학교 분실물`: 장난감, 책가방, 실험도구 테마
- `우주 해적 창고`: 보물, 지도, 저주받은 물건 테마
- `시간 여행자 주간`: 낡음/복원 규칙 중심 이벤트
- `희귀 분실물 도감`: 특수 물건 컬렉션

## Prototype Scope

- 슬롯 기반 보관함
- 물건 4종: 일반 물건, 반중력 우산, 시간 장난감, 별 조각
- 장치 2종: 안정화 상자, 복원 장치
- 주인 주문 3개
- 10개 수제 레벨

## Release Potential

강점은 컨셉 확장성이 매우 크고, 이벤트/도감/컬렉션 구조가 자연스럽다는 점이다. 물건 하나하나가 캐릭터처럼 작동할 수 있어 스토어 이미지와 영상 소재도 만들기 좋다.

약점은 규칙이 많아질수록 퍼즐의 공정성이 떨어질 수 있다는 점이다. 모든 특수 물건은 짧은 시각 피드백과 예측 표시가 필요하다.

## Risks

- 너무 많은 특수 물건은 학습 피로를 만든다.
- 자동 레벨 검증 없이 복제/흡수 규칙을 쓰면 막힌 레벨이 생기기 쉽다.
- 컨셉은 강하지만 첫 5초 설명은 `물건을 주인에게 돌려준다`로 단순화해야 한다.

## Open Questions

- 물건 속성은 얼마나 기괴하게 허용할 것인가?
- 도감/컬렉션을 핵심 동기로 쓸 것인가?
- 보드 게임형인지, 주문 처리형인지 방향을 정해야 한다.
