# Monster Hotel Room Service

## One Line Pitch

괴물 호텔에서 손님의 금기 조건을 피해 음식과 물건을 올바른 방에 배달하는 퍼즐.

## Player Fantasy

플레이어는 밤마다 문을 여는 괴물 호텔의 룸서비스 매니저다. 손님은 뱀파이어, 늑대인간, 슬라임, 유령, 미라처럼 각자 특이한 요구와 금기를 가진다.

## Core Loop

1. 방마다 손님 주문과 금기 조건을 확인한다.
2. 음식, 물건, 포장 상태를 제한된 카트에 싣는다.
3. 충돌하는 아이템을 피하고 순서를 맞춰 배달한다.
4. 모든 주문을 만족하면 클리어한다.

## One-Hand Control

- 아이템 탭: 카트에 싣기
- 방 탭: 배달
- 카트 슬롯 드래그: 순서 변경
- 손님 홀드: 금기 조건 보기
- 되돌리기: 마지막 적재/배달 취소

## Puzzle Rules

- `뱀파이어`는 마늘 옆 음식을 받을 수 없다.
- `늑대인간`은 달 아이템을 보면 주문이 바뀐다.
- `슬라임`은 인접한 음식 두 개를 합친다.
- `유령`은 카트 공간을 차지하지 않지만 순서를 무시하고 먼저 배달된다.
- `미라`는 포장된 음식만 받을 수 있다.
- `프랑켄슈타인`은 전기 아이템이 있으면 추가 보상을 준다.
- 같은 층 손님을 연속 배달하면 콤보가 붙는다.

## Level Production Model

- 방 수
- 손님 종류
- 주문 아이템 수
- 카트 슬롯 수
- 금기 조건 수
- 배달 순서 조건
- 아이템 조합 규칙
- 제한 턴

이 컨셉은 레벨 생산성이 높다. 손님 타입과 아이템 조합만 바꿔도 많은 레벨이 나온다.

## Difficulty Curve

- 1-10레벨: 단순 주문 매칭
- 11-20레벨: 카트 공간 제한
- 21-35레벨: 금기 조건 추가
- 36-50레벨: 인접 아이템 반응 추가
- 51레벨 이후: 손님 상태 변화, 층 콤보, 이벤트 손님 조합

## Event And LiveOps Fit

- `할로윈 시즌`: 특수 손님과 사탕 주문
- `보름달 주간`: 늑대인간 변신 규칙 강화
- `겨울 호텔`: 따뜻한 음식, 얼어붙는 아이템
- `VIP 손님`: 일일 고난도 주문
- 방 꾸미기, 카트 스킨, 호텔 층 테마가 자연스럽게 붙는다.

## Prototype Scope

- 방 4개
- 카트 슬롯 3개
- 손님 3종: 뱀파이어, 슬라임, 미라
- 아이템 6종
- 금기 조건 2종
- 10개 수제 레벨

## Release Potential

강점은 캐릭터성이 좋고, 이벤트/스킨/시즌 확장이 매우 쉽다는 점이다. 모바일 퍼즐에서 중요한 짧은 판 길이와 명확한 실패 이유도 만들기 쉽다.

약점은 룸서비스/호텔 테마가 완전히 새로운 구조는 아니므로 캐릭터 연출과 규칙 조합으로 차별화해야 한다.

## Risks

- 손님 조건이 텍스트 의존적이면 현지화와 UX 비용이 커진다.
- 아이템 인접 반응은 예측 표시가 없으면 불공정하게 느껴질 수 있다.
- 캐릭터성에 기대면 실제 퍼즐 깊이가 약해질 수 있다.
